# NeoLogger

Notepad++ 风格的日志分析工作台，纯 Rust + egui 实现。

## 功能

- **多文件按时间合并**：选择任意多个日志文件，按插件解析出的纳秒时间戳做稳定 k 路归并；时间相同的行保持各文件内部顺序。
- **多标签视图**：每个文件一个顶层标签，合并结果也是独立标签。
- **单行外壳**：文件 / 编辑 / 显示 / 主题 / 视图 / 高亮 / 帮助 七个菜单收进左上角 `☰`，与侧栏开关、可横向滚动的标签条共用一行；菜单项显示快捷键并在不可用时置灰，品牌标识收进 `☰` 菜单顶部。`F1` 打开快捷键总览，帮助菜单还可查看版本、会话文件与动态插件目录。
- **可切换主题**：主题菜单提供深色 / 浅色 / 高对比三套配色，切换立即生效并写入配置目录的 `ui.conf`，下次启动自动沿用；日志级别与高亮颜色在浅色主题下自动加深以保证对比度。
- **日志行右键菜单**：右键任意日志行即可复制整行 / 选中内容 / 单词、切换书签、按词做文字或整行高亮、按该词 / 级别 / 模块在当前标签页派生过滤视图、在全部文件中搜索，折叠模式下还可展开或收起该组。
- **侧栏浮层抽屉**：`F9`、标签行的 `◧` 或显示菜单打开工作区侧栏；它以浮层覆盖日志左侧，不再预留 312px 布局宽度，`Esc`、`×` 或点击日志区即可收起，开关状态写入 `ui.conf`。
- **过滤栏可收起**：显示菜单取消勾选“过滤栏”即可收起顶部过滤栏；过滤条件、活动视图与书签保持不变，需要时再展开，状态同样写入 `ui.conf`。
- **Tab 承载视图栈**：一个标签页就是一个根视图（文件或合并结果），过滤栏、右键筛选与标签条上的 `＋` 都在当前标签页内压入新的过滤层级，层级不限；切换标签页时恢复各自停在的层级，父视图变化会级联重算所有后代。
- **按需展开的视图栈**：活动标签页上的路径 chip 显示派生层级（`文件 › 查询 › 查询`），点开才展开完整视图栈：点击任一级直接跳转，每级右侧 `×` 移除该级（子视图自动上移到父级并重算）。导航只占一行，不再有常驻面包屑行。
- **视图重命名与备注**：右键标签页，或在视图栈中右键某一级即可改名并写备注；名称留空恢复自动命名，备注显示在悬停提示中，随会话一起保存。
- **书签**：点击行号栏左侧圆点或 `Ctrl+B`，侧栏可跳转；书签锚定物理行，跨过滤/合并视图保持稳定。
- **关键词高亮**：输入关键词选择“整行背景”或“文字着色”；也可以直接双击日志中的 token 生成行背景规则。
- **可插拔日志插件**：按文件自动探测 ROS 2 / Python logging / 通用文本，插件决定时间戳、级别、模块、行样式与文字装饰；还可在配置目录放 JSON 声明新格式，无需重新编译。
- **会话持久化**：视图层级（含自定义名称与备注）、书签、高亮规则与当前标签页自动保存，下次启动原样恢复。
- **tail 跟随**：勾选“跟随”后每 600ms 检查文件变化，重载并自动滚到底部。
- **手动重载与轮转检测**：`F5` 或文件菜单“重新加载全部”随时从磁盘重读全部文件；跟随与重载时按创建时间、文件长度和 4 KB 前缀区分“追加”与“轮转/重写”，重写时自动丢弃该文件已失效的书签，并在状态栏说明。
- **百万行过滤**：过滤结果用位图存储（每父行 1 bit + 秩索引），内存约为 `Vec<LineRef>` 的 1/64；级别/模块/时间戳解析走无正则的字节扫描，过滤与渲染热路径不产生逐行临时分配；正则过滤与正则查找先从表达式提取“必须出现”的字面量做预筛，只有候选行才进入正则引擎；`field:` 过滤先按 `=` 位置直接定位字段，纯 ASCII 无引号的行不再逐 token 分词；可视行的样式、高亮与排版结果按行缓存，滚动帧只做哈希查找。
- **多行文本选择与自动换行**：在文本上拖拽可跨行选择，拖到视口边缘自动滚动；点击行号栏或三击选中整行，拖过行号栏选择连续多行；`Ctrl+A` 全选当前视图，`Esc` 清除选区，`Ctrl+C` 复制；可切换软换行。
- **非破坏性查找**：`Ctrl+F` 在当前视图中查找，支持 `.*` 正则、`Aa` 区分大小写、`全词` 匹配与查询历史；命中高亮并显示 `i/N`，`F3` / `Shift+F3` 上下跳转，不改变过滤条件。
- **全局搜索**：`Ctrl+Shift+F` 在所有打开的文件中搜索（同样的选项），结果按文件列出文档、行号、时间与命中上下文；点击直接切到对应文件并在目标行高亮，单次最多返回 5000 条。
- **行跳转与缩放**：`Ctrl+G` 按行号跳转；`Home` / `End` / `PgUp` / `PgDn` 翻页；`Ctrl+滚轮`、`Ctrl++` / `Ctrl+-` 调整字号，`Ctrl+0` 恢复默认。
- **统计浮窗**：级别与模块计数（点击直接派生筛选视图）、时间直方图（点击按时段派生子视图）、时间间隙 Top（点击跳到断档后的第一行）；以可拖动、可缩放的浮动窗口显示，不再占用右侧 280px，开关状态写入 `ui.conf`。
- **重复日志折叠**：相邻且仅数字不同的行折叠为一行显示 `×N`，点击展开；与软换行互斥。
- **列对齐视图**：由插件把每行拆成时间 / 级别 / 模块 / 消息四栏，表头对齐、消息列超宽裁剪；保留装饰、规则与查找高亮，选区与双击取词映射回原始字节。与软换行、折叠互斥。
- **结构化字段过滤**：logfmt 行可用 `field:key=value` 过滤；内置 JSON Lines 插件解析 `timestamp` / `level` / `module` 等字段并支持嵌套路径。

## 构建与运行

需要稳定版 Rust 工具链（仓库在 1.98 上开发），Windows / Linux / macOS 均可。

```bash
cargo run -p neolog-app          # 启动 GUI，优先恢复上次会话，否则载入示例
cargo test --workspace             # core 65 + plugins 17 + app 15 项测试
cargo run --release --example perf -p neolog-plugins   # 百万行基准（打开/过滤/查找/逐行解析）
cargo build --release -p neolog-app
```

首次启动会显示两组示例日志及一个合并视图，可直接体验。之后启动会优先恢复 `%APPDATA%/neo-log/session.json`；文件缺失或快照损坏时回退到示例。Windows 下会自动加载 Microsoft YaHei / SimHei 作为 CJK 回退字体。

> 配置目录：Windows 为 `%APPDATA%\neo-log`，Linux/macOS 依次使用 `$XDG_CONFIG_HOME/neo-log`、`~/.config/neo-log`。会话文件为其中的 `session.json`，界面偏好（主题、侧栏/统计/过滤栏开关）在 `ui.conf`，声明式插件放在其中的 `plugins/`。

## 过滤语法

空格分隔，所有词项 AND；双引号保留空格；`!` 取反。

| 示例 | 含义 |
| --- | --- |
| `error timeout` | 同时包含两个子串（ASCII 不区分大小写） |
| `"connection reset"` | 短语匹配 |
| `!debug` | 排除包含 debug 的行 |
| `re:failed to .*` | 正则，始终不区分大小写 |
| `module:planner` | 插件解析出的模块名包含 planner |
| `level>=warn` | WARN 及以上（支持 `>` `>=` `=` `<=` `<`） |
| `field:pid=4242` | 结构化字段：logfmt 的 `key=value`，或 JSON Lines 的字段（支持 `a.b` 嵌套） |
| `time:08:00:00..09:00:00` | 按「时刻」过滤，半开区间 `[起, 止)`；跨天日志会同时命中每天该时段 |
| `bm:` | 仅书签行 |

正则错误、未知级别、引号未闭合会在状态栏给出中文提示。

## 编写插件

### 方式一：JSON 声明式插件（无需编译）

把 `*.json` 放进配置目录的 `plugins/` 下，重启即生效；具体字段见 [examples/plugins/service-log.json](examples/plugins/service-log.json)。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` / `name` | 是 | 唯一标识与显示名 |
| `sniff` / `sniff_score` | 否 | 样例行包含任一子串即命中，得分默认 0.75 |
| `timestamp.regex` | 否 | 时间戳正则；`mode: "common"` 交给通用解析器，`mode: "epoch"` 用 `sec_group` + `nanos_group` |
| `severity` / `module` | 否 | `{ "regex": ..., "group": n }`，分别解析级别与模块 |
| `decorate` | 否 | 正则命中文本着色：`fg` / `bg`（`[r,g,b]`）、`bold` |
| `severity_styles` | 否 | 按级别覆盖整行样式（背景色/前景色/粗体） |

加载失败（JSON 语法、无效正则、未知级别）不会中断启动，错误会显示在状态栏并打印到 stderr。

### 方式二：编译进程序的 Rust 插件

在 `crates/plugins/src/` 新增实现并注册：

```rust
use std::path::Path;
use neolog_core::{LogPlugin, RowStyle, Severity, StyledSpan};

pub struct MyPlugin;

impl LogPlugin for MyPlugin {
    fn id(&self) -> &str { "my-log" }
    fn name(&self) -> &str { "My Service" }

    fn sniff(&self, path: &Path, sample: &[&str]) -> f32 {
        let hits = sample.iter().filter(|l| l.starts_with("MYLOG ")).count();
        if hits > 0 { 0.8 } else { 0.0 }
    }

    fn timestamp(&self, line: &str, _day_base: i64) -> Option<i64> {
        // 解析 "MYLOG <RFC3339>"，返回纳秒
        None
    }

    fn severity(&self, line: &str) -> Option<Severity> {
        line.split_whitespace().find_map(Severity::parse)
    }

    fn decorate(&self, _line: &str, _out: &mut Vec<StyledSpan>) {}
    fn row_style(&self, line: &str) -> RowStyle {
        neolog_core::plugin::row_style_for(self.severity(line))
    }
}
```

然后在 `builtin_plugins()` 中加入 `Arc::new(MyPlugin)`。`sniff` 返回 0 表示不匹配；注册表选择分数最高者，全部为 0 时回退纯文本插件。

## 当前限制

- 日志只读，不支持编辑与保存。
- `bm:` 是过滤时快照：筛选后再增删书签，需要重新派生或应用过滤。
- 跟随与轮转检测使用 600ms 轮询（长度、修改时间、创建时间 + 4 KB 前缀哈希）：等长且只改 4 KB 之后内容的就地改写可能漏检；Windows 上日志文件保持内存映射，其他进程对同一文件做 `copytruncate` 会被系统拒绝（rename + 新建式轮转正常）。
- 会话仅在手动“保存会话”或正常关闭窗口时写入；示例文档和不存在于磁盘的路径不会被持久化（打开真实文件时会自动丢弃纯示例工作区）。
- 动态插件是声明式 JSON，不支持执行任意代码；需要复杂解析逻辑仍需编译进内置插件。
- 自动换行按等宽字符宽度估算列宽，CJK 已计入，组合字符/emoji 可能与实际排版相差 1 列。
- 插件正则逐行实时匹配，未做结果缓存；超大文件上复杂正则会持续消耗 CPU。
- `time:` 与直方图按「一天中的时刻」取模匹配，不支持跨午夜区间（如 `23:00..01:00`），也不区分日期。
- 重复行折叠只合并「相邻」且规范化后（数字→`#`、ASCII 小写）相同的行；跨非连续行不做全局模板聚合，且与软换行互斥。
- 列对齐视图依赖插件给出的列切分：无前缀的续行（如堆栈）只占消息列；声明式插件要求字段按「时间 → 级别 → 模块」顺序出现且中间只有分隔符，否则这些字段留在消息里。时间列按 UTC 显示，跨天时补 `MM-DD`。
- `field:` 语义由当前插件决定：默认解析 logfmt `key=value`；JSON Lines 插件按 JSON 字段（含嵌套路径）查找，其它插件无结构化字段时不会命中。
- 查找是当前视图内的非破坏性高亮 + 行跳转，不生成子视图，也不跨标签搜索；跨标签请用全局搜索。
- 全局搜索按文件顺序返回结果、单次上限 5000 条（超出会显示“已截断”），且不按时间合并；查找历史仅保存在本次运行的内存中。
- “全词”以字母/数字/下划线为词字符（CJK 也算词字符），因此对连续中文做整词匹配时不会命中词内部。
- 正则查找沿用 Rust `regex` 语法（不支持反向引用与环视）；非法正则在查找栏与状态栏给出中文错误。
